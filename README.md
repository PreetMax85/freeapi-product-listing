# FreeAPI Product Listing

A simple e-commerce style product listing interface built with vanilla JavaScript.

## Features

- Product card grid with image, title, price & rating
- Search by product name (client-side)
- Filter by category
- Star rating display
- Load more pagination
- Loading skeletons & error handling

## Tech Stack

- HTML, CSS, JavaScript (no frameworks)
- Tailwind CSS (CDN)
- FreeAPI Random Products endpoint

## API Endpoint Used

```
GET https://api.freeapi.app/api/v1/public/randomproducts
```
